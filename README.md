## 📚 Projects Included

### 1. 🎮 Rock Paper Scissors Game

A simple command-line based Rock Paper Scissors game where the user plays against the computer.

**Features:**

* Rock, Scissor and Paper choices
* Computer makes a random choice
* 5 rounds of gameplay
* User and computer score tracking
* Draw detection
* Final winner calculation

**Concepts Used:**

* `random` module
* `while` loop
* `for` loop
* `if-elif-else`
* User input
* Variables
* Conditional operators

---

### 2. 🔢 Number Guessing Game

A simple game where the computer randomly generates a number between **1 and 100**, and the user tries to guess it.

**Features:**

* Random number generation
* User input
* Checks whether the guess is:

  * Too high
  * Too low
  * Correct

**Concepts Used:**

* `random` module
* `random.randrange()`
* `if-elif-else`
* User input
* Comparison operators

---

### 3. 🏍️ Bike Rental System

A simple command-line based **Bike Rental System** developed using Python Object-Oriented Programming.

The system allows users to check the available bike stock and rent bikes by entering the required quantity.

**Features:**

* Display available bikes
* Rent multiple bikes
* Calculate rental price
* Automatically update available stock
* Check invalid quantity
* Prevent renting more bikes than available
* Exit option

**Rental Price:**

```text
₹100 per bike
```

**Concepts Used:**

* Classes and Objects
* `__init__()` constructor
* Instance variables
* Methods
* `self`
* `if-elif-else`
* `while` loop
* User input
* Arithmetic operators
* Object-Oriented Programming

**Example:**

```text
1 Display Stocks
2 Rent a Bike
3 Exit

Enter your choice: 2
Enter The QTY: 5

Total Prices: 500
Total Bikes: 95
```

## ▶️ How to Run the Projects

### 1. Clone the Repository

```bash

```

### 2. Open the Project

```bash
cd PYTHONPROJECT
```

### 3. Run a Python Project

For example:

```bash

```

or:

```bash
python number_guessing.py
```

or:

```bash
python bike_rental.py
```
